about=AHN Streamer loads the point clouds of the Actueel Hoogtebestand Nederland (AHN, the Dutch national elevation dataset) for the current map canvas as Cloud Optimized Point Clouds (COPC), straight from the official AHN storage. QGIS fetches only the level of detail it needs through HTTP range requests, so nothing has to be downloaded or converted. Choose AHN2 to AHN6 or "newest available" per 1 km sheet, filter by class (ground, buildings, water, ...), pick a style (classification, height, intensity, number of returns, RGB for AHN6), and optionally merge all tiles into one virtual point cloud (VPC). Also available in the Processing Toolbox, for models and scripts. Coverage: the European Netherlands only. No external dependencies. Data: AHN (www.ahn.nl); AHN1-4 are CC0, AHN5-6 are CC BY 4.0, so attribution is required. The user interface is available in English and Dutch and follows the QGIS language setting.
